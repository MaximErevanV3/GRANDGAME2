**GRAND CITY 2** — ретро-футуристичный неоновый открытый мир в браузере,
в духе классической GTA 2. Чистый JavaScript + Three.js. Ноль внешних ассетов:
каждая текстура, звук и житель города генерируется кодом.

## Что это

Ночной мегаполис 8×8 кварталов: мокрые отражающие дороги, неоновые вывески,
дождь, динамические тени и bloom. Садишься в любую машину, дрифтишь с ручником,
угоняешь транспорт, стреляешь, уходишь от полиции на пятизвёздочном розыске —
или встречаешь «ПОТРАЧЕНО» на асфальте.

> **Почему чистый JavaScript, а не TypeScript/Java?**
> По требованию заказчика проект переписан с TypeScript на «джаву».
> Настоящая Java в браузере не исполняется (апплеты мертвы с 2015 года),
> а родной язык браузера — это **JavaScript**, поэтому движок переписан
> именно на него: без этапа компиляции, без типов, код запускается как есть.

## Возможности

| Категория | Что внутри |
| --- | --- |
| **Мир** | Процедурный город 448×448 м: 64 квартала, даунтаун, парки, парковки, центральная площадь с фонтаном, зебры, разметка |
| **Свет** | Bloom-постобработка, HDR-эмиссия окон и неона, «луна» с картой теней 2048px, настоящие SpotLight-фары игрока, световые лужи под фонарями |
| **Машины** | 4 класса (компакт/спорткар/такси/полиция), физика с продольной/боковой скоростью, дрифт с ручника, следы шин, дым, искры, урон, пожар и взрывы с цепной детонацией |
| **Пешеходы** | Толпа гуляет по тротуарам, паникует от стрельбы, разбегается, гибнет под колёсами — с кровью и лужами |
| **Оружие** | Пистолет: хитскан, трассеры, вспышки, отскоки искр от стен, перезарядка, патроны |
| **Полиция** | 5 звёзд розыска, патрули с погоней и упреждением, тараны, стрельба копов, двухтоновая сирена, арест «ПОЙМАН» |
| **Пикапы** | Аптечки и патроны с респауном |
| **Меню** | Главное меню, настройки (качество/тени/bloom/дождь/громкость/тряска — с сохранением), пауза, экраны конца со статистикой |
| **HUD** | Спидометр, вращающаяся миникарта, звёзды розыска, здоровье, патроны, тосты, прицел |
| **Звук** | Полностью синтезированный WebAudio: двигатель по скорости, визг заноса, выстрелы, взрывы, сирена, дождь |
| **Погода** | Дождь с частицами + «мокрый» блеск асфальта |

## Управление

| Действие | Клавиша |
| --- | --- |
| Газ / тормоз-задний | `W` / `S` (или стрелки) |
| Поворот | `A` / `D` |
| **Ручник (дрифт!)** | `ПРОБЕЛ` |
| Сесть / выйти / **угнать** | `F` |
| Фары | `L` |
| Стрелять | **ЛКМ** (мышь — прицел) |
| Перезарядка | `R` |
| Пауза | `ESC` |

## Запуск

### Вариант 1 — GitHub Pages (без установки чего-либо)
1. Fork/открой этот репозиторий.
2. **Settings → Pages → Source: Deploy from a branch → `main` / (root) → Save**.
3. Через минуту игра живёт на `https://<ваш-ник>.github.io/GRANDGAME2/`
   (Three.js подгружается с CDN через import map).

### Вариант 2 — локально (Node.js 18+)
```bash
git clone https://github.com/MaximErevanV3/GRANDGAME2.git
cd GRANDGAME2
npm install
npm run dev        # http://localhost:5173
```

### Вариант 3 — продакшн-сборка
```bash
npm run build      # dist/
npm run preview
```

## Оптимизации

- **~10 draw-call'ов на кадр для всей статики**: кварталы, дороги, тротуары,
  вывески и лужи мержатся в единые геометрии; UV тайлинга запечён в атрибуты.
- **InstancedMesh**: все колёса всех машин — один меш; фонари и деревья — тоже.
- **Кольцевые буферы** для частиц и декалей — ноль аллокаций в кадре.
- Затухание следов шин и крови считается **на GPU** (шейдер с `uTime`).
- Пресеты качества: тени/bloom/pixelRatio/плотность трафика и толпы.
- `dt = min(delta, 0.05)` — симуляция не «взрывается» на лагах.

## Лог обновлений

### v3.0.0 — «Глобальная модернизация» (текущий релиз)
- **Миграция с TypeScript на чистый JavaScript** (ES-модули, без сборки типов).
- **Меню и UI**: главное меню с кинематографичной орбитой камеры над живым
  городом, настройки с мгновенным применением и сохранением, пауза,
  экраны «ПОТРАЧЕНО»/«ПОЙМАН» со статистикой забега.
- **Графика 2.5D**: пере-генерация текстур (фасады 4 типов со светящимися
  окнами, атлас неоновых вывесок, «мокрый» асфальт), световые лужи
  под фонарями и вывесками, маячки на антеннах, дождь.
- **Генерация мира**: парки с деревьями, парковки с размеченными местами,
  центральная площадь с фонтаном, припаркованные у обочин машины.
- **Пешеходы**: маршруты по тротуарам, паника, «рэгдолл», кровь (частицы
  + растущие лужи), сбивание машинами.
- **Оружие и стрельба**: пистолет с хитсканом, трассеры, вспышки, гильзы
  искр от стен, перезарядка, пикапы патронов.
- **Полиция и розыск**: 5 звёзд, теплота/затухание, патрули с погоней и
  упреждением, стрельба копов со 2 звезды, арест на пешке, сирена.
- **Физика переписана**: скорость хранится в осях машины и перепроецируется
  при повороте — настоящий дрифт с ручника (`ПРОБЕЛ`), доворот от
  скольжения, капсульные коллизии со скольжением и искрами.
- **Машины**: классы, урон, дым/огонь, взрывы с цепной детонацией, угон
  (водителя вышвыривает — и он убегает), фары игрока — реальные SpotLight.
- **Звук**: полностью синтезированный WebAudio-движок.
- **Оптимизация**: см. раздел выше.

### v1.0 — «Шаг 1» (предыдущая итерация)
- Каркас: Vite + TypeScript + Three.js (EffectComposer + UnrealBloom).
- Город 6×6, базовая физика машины, HUD-прототип.

### Дорожная карта v3.1+
- Миссии и телефон-заказы, деньги, оружие в подборах (Узи/Дробовик),
- Мотоциклы и грузовики, трамвай на рельсах,
- Мини-карта с целью-маркером, сохранение прогресса,
- Погода: гроза с молниями, туман.
